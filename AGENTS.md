# AGENTS.md — Particle Cosmos

## Architecture

Single-page Vite + React app (no router). The 3D scene is a `@react-three/fiber` `<Canvas>` rendered full-screen behind a DOM HUD. One Netlify Function backs saved presets; Netlify Identity provides optional auth.

```
src/
  App.tsx                 Layout shell: masthead, telemetry, frame, mounts Cosmos/ControlPanel/AccountBar
  components/Cosmos.tsx   Canvas, particle simulation (Field), background stars (Dust)
  components/ControlPanel.tsx  Slider groups + palette selector (desktop rail / mobile bottom sheet)
  components/Slider.tsx   Hairline range input with eased numeric readout
  components/AccountBar.tsx    Bottom-right status bar, auth form, presets manager
  lib/settings.ts         Settings type, palettes, slider specs, defaults, normalizeSettings
  lib/useAuth.ts          Identity state + handleAuthCallback on load
  lib/presets.ts          fetch client for /api/presets
  lib/useEased.ts         rAF number easing for readouts
db/schema.ts, db/index.ts Drizzle schema + client (drizzle-orm/netlify-db)
netlify/functions/presets.mts  GET/POST /api/presets, DELETE /api/presets/:id
netlify/database/migrations/   Generated by drizzle-kit — never hand-edit
```

## Non-obvious decisions

- **Settings flow via a ref, not props.** `App` keeps settings in state for the HUD and mirrors them into `settingsRef`; the frame loop reads the ref so slider changes never re-render the canvas. Inside the loop every parameter (including particle count and palette colours) is exponentially eased toward its target — this is what gives the "heavy" feel. Keep new parameters eased the same way.
- **Simulation is CPU-side** over preallocated `Float32Array`s sized to `MAX_PARTICLES` (120k). Density changes only move `geometry.setDrawRange`; inactive particles are skipped, not deallocated. Each particle springs toward an orbiting "home" point plus sine-based turbulence; cursor force, swirl, stir and shockwave bands are added as accelerations, then velocity is damped (`exp(-dt*1.9)`). `dt` is clamped to 1/30. A `uDim` uniform lowers per-particle alpha as the count grows so additive blending doesn't blow out to white.
- **Camera** is custom spherical coordinates with velocity + damping (no OrbitControls) so drag inertia, pinch, wheel and parallax share one integrator. A pointer-up with < ~8px travel and < 450ms counts as a click → shockwave.
- **Telemetry** is pushed to React only twice per second.
- **Auth is browser-side** (`login`/`signup`/`logout` from `@netlify/identity`), which sets the `nf_jwt` cookie; the function calls `getUser()` server-side from that cookie. Presets are scoped by Identity `user.id`; `(user_id, name)` is unique and saving an existing name overwrites it.
- The function validates settings server-side (numeric keys in [-20, 20] — density up to 200 — known palette id). If you add a setting or palette, update `NUMERIC_KEYS`/`PALETTES` in `presets.mts` too; the client runs `normalizeSettings` on load so old presets stay valid.
- Popovers that hold readable text (auth form, presets, notices, status bar) use the near-opaque `.glass-solid` surface, not `.glass`, so particles behind them don't hurt legibility.
- **OAuth buttons are settings-driven.** `OAuthButtons` lists every provider `@netlify/identity` supports but only renders those `getSettings().providers` reports as enabled, so enabling one in the dashboard (Facebook needs its own app credentials) makes it appear with no code change.
- Guest settings persist to `localStorage` (`particle-cosmos:settings`) as a convenience only.

## Conventions

- Design language: sharp corners (no rounded cards), `border-white/10` hairlines, `.glass` surfaces, monospace UI text with Instrument Serif italic for display headings, accent colour via CSS vars `--accent*` set from the active palette.
- Custom CSS in `src/index.css` is **unlayered**, so it beats Tailwind utilities — don't put `position`, `width`, etc. on shared classes used together with layout utilities.
- Easing: `cubic-bezier(0.16,1,0.3,1)` / long durations (500–1000ms) for UI transitions.
- Identity must stay enabled via the skill's `enable.cjs`; use `@netlify/identity` only (never the legacy widget).
